Re-explain the previous reply, or the part the user points at, as the shortest plain-English
version that would let the user explain it to a colleague.

- Short enough to take in at a glance. Lead with the answer and stop once it makes sense; a list
  stays a list, with each item cut to its point.
- Plain prose only: no headings, no bold labels, no line per aspect of the problem.
- Use plain words. Keep a term only if colleagues will say it, and gloss it in passing.
- Swap an abstract rule for a concrete example rather than giving both.
- Cut detail, never a decision: drop nothing the user must act on or would decide differently
  without.
- Stay in this register for follow-ups on the same topic.
